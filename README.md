# GWEP Dashboard (`gwep-dashboard`)

Marketing KPI dashboard and executive brief for **GWEP Cumbres Herradura**.

## GitHub Pages

This site is published from the **`docs/`** folder on branch **`main`** (GitHub only allows **`/`** or **`/docs`**).

1. Open **Settings → Pages** in this repository.
2. **Source:** Deploy from a branch.
3. **Branch:** `main` → **Folder:** `/docs` → Save.

After the workflow finishes (~1–2 minutes):

| Page | URL |
|------|-----|
| Dashboard | `https://deborahdana.github.io/gwep-dashboard/` |
| Executive brief | `https://deborahdana.github.io/gwep-dashboard/executive-brief.html` |

## Repository layout

- **`docs/`** — Static site (GitHub Pages).
- **`GWEP/`** — Agent prompts, weekly KPI CSV templates, and insights docs.

## Updates

Edit files under `docs/` or `GWEP/insights/`, then commit and push; Pages rebuilds automatically.
